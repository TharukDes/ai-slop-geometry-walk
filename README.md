# ai-slop-geometry-walk

What kind of game did you try to make?
We made a side-scrolling geometry dash shooter.

How far did you get?
We changed the visuals for the enemies, added a score system, and made a boss appear every 5000 points.

Was there any particular step where the agent had trouble understanding you?
It misunderstood the first request and created a different base game than intended. However, we just decided to continue with the idea that it had.

Did you make any requests too big for the agent to quickly complete?
The initial request was extremely large, and took a while to complete, but it made the basis of the game. Otherwise, all the other requests were simple additions and did not take long. 

Was there any particular step where you had trouble understanding what the agent was saying? After the agent explained, can you explain the issue here?
We had to rerun the game to see the updated boss attacks, but after reading the agent's messages that became apparent.
